# 单次骑行数据解读 · 骑行运动科学知识库

> 用途：为 AI 解读单次骑行数据提供维度化的运动科学依据、指标定义、基准范围与解读逻辑。
> 覆盖维度：配速执行 / 爬坡表现 / 心率负荷 / 功率输出 / 强度与训练负荷 / 踏频策略 / 跨传感器配合

## 1. 配速执行 (pacingExecution)

### 1.1 核心概念
配速执行是指骑手在一次骑行中，功率、速度或心率随时间分布的控制质量。理想配速不是恒定功率，而是根据地形、风向和体能状态动态调整的"生理恒速"——保持恒定的生理消耗（RPE / 心率区间），而非恒定的机械输出。

### 1.2 关键指标

| 指标 | 定义 | 计算方法 |
|------|------|----------|
| **前半/后半功率差** (Split Difference) | 前后半程 NP 的差值百分比 | (后半NP - 前半NP) / 前半NP × 100% |
| **变速系数** (Variability Index, VI) | NP 与平均功率的比值，反映功率波动程度 | VI = NP / 平均功率 |
| **停歇时间占比** | 骑行中完全停止或极低功率（<50W）的时间比例 | 停歇时间 / 总时间 × 100% |
| **爬升段功率/下降段功率比** | 上坡与下坡的功率分布对比 | 爬坡段平均功率 / 下坡段平均功率 |
| **负分割执行** (Negative Split) | 后半程是否比前半程更快/更强 | 见下方分级 |

### 1.3 基准范围与分级

**Variability Index (VI) 解读：**
- VI = 1.00–1.05：非常稳定（计时赛/室内训练）
- VI = 1.05–1.15：正常户外起伏骑行
- VI = 1.15–1.25：波动较大（包含爬坡/拉扯）
- VI > 1.25：波动剧烈（比赛/含大量间歇）

**负分割 (Negative Split) 分级：**
- 后半程比前半程高 2–5%：理想负分割（耐力骑行/长距离赛事）
- 前后差 ±2% 以内：匀速配速（Perfectly Even）
- 前半程比后半程高 >5%：正分割/前快后崩（过早发力）

### 1.4 解读逻辑（AI 判断规则）

**✅ 良好配速执行信号：**
- 爬坡段功率略升、平路/下坡段略降的"地形自适应配速"（坡度+1% → 功率+3–5%）
- 长距离骑行后半程功率下降 ≤3%（在同心率下）
- VI 与地形复杂度匹配（平路 VI 低、山路 VI 高）
- 前 20 分钟功率不超过计划目标的 105%

**⚠️ 配速问题信号：**
- 前 15–30 分钟功率显著高于全程均值（"肾上腺素开局"）
- 爬坡时功率 spike 过大（>20% 目标 W/kg），下坡时完全松脚
- 长距离骑行后半程功率衰减 >10%（同心率下）
- 停歇次数多、单次停歇时间长（>5 分钟/次），说明补给或节奏管理差

### 1.5 运动科学依据
- **地形自适应配速**：上坡时空气阻力下降、重力阻力上升，每瓦功率节省的时间更多；因此上坡多输出功率、下坡少输出，相同平均功率下完成时间更短（Gordon, 1995；运动仿真研究证实可提升 2–3%）。
- **负分割优势**：长距离骑行（>2h）中，前半程保守 5–10W、后半程提升，可避免早期糖原耗竭和代谢副产物堆积，总表现更优。
- **心率滞后效应**：心率对功率变化有 20–30 秒滞后，因此功率是配速控制的首选即时指标，心率用于验证生理负荷。

## 2. 爬坡表现 (climbPerformance)

### 2.1 核心概念
爬坡表现由**功率体重比 (W/kg)** 主导，因为坡度 >6% 时重力阻力远大于空气阻力和滚动阻力。W/kg 是预测爬坡速度的最佳单一指标。

### 2.2 关键指标

| 指标 | 定义 | 说明 |
|------|------|------|
| **爬坡 W/kg** | 爬坡段平均功率 / 体重 | 爬坡核心指标 |
| **VAM** (Vertical Ascent Meteric) | 垂直爬升速率（米/小时） | VAM = 爬升高度 / 时间 × 3600 |
| **坡度-功率匹配度** | 不同坡度段的 W/kg 是否一致 | 同一次骑行中，不同坡度段的 W/kg 应相近 |
| **爬坡功率衰减率** | 长爬坡中后半段 vs 前半段 W/kg 下降 | 反映爬坡耐力 |
| **有效爬升高度** | 扣除假爬升（下坡+上坡连续）后的净爬升 | 用于计算真实爬坡效率 |

### 2.3 基准范围与分级

**FTP W/kg 骑手分级（男性参考）：**

| 水平 | FTP W/kg | 描述 |
|------|-----------|------|
| 新手/休闲 | 2.0–2.8 | 休闲骑行，爬坡吃力 |
| 经常训练 | 2.8–3.5 | 能完成阿尔卑斯式山口 |
| 业余强手 | 3.5–4.2 | 业余比赛中上游 |
| Cat 3–2 | 4.0–4.5 | 业余联赛中级 |
| Cat 1–精英业余 | 4.5–5.5 | 业余顶尖 |
| Pro 洲际队 | 5.5–6.0 | 职业队水平 |
| World Tour 爬坡手 | 6.0–6.5+ | 环法级 GC/爬坡手 |

**典型爬坡速度参考（75kg 骑手 + 8kg 车）：**

| W/kg | 8% 坡度 | 10% 坡度 |
|------|---------|----------|
| 2.0 | ~10 km/h | ~8 km/h |
| 3.0 | ~14 km/h | ~11 km/h |
| 4.0 | ~18 km/h | ~14 km/h |
| 5.0 | ~22 km/h | ~17 km/h |

**VAM 参考值：**
- 休闲骑手：500–800 m/h
- 训练有素：800–1200 m/h
- 业余竞赛：1200–1600 m/h
- 职业车手：1600–2000+ m/h（短陡坡）

### 2.4 解读逻辑（AI 判断规则）

**✅ 良好爬坡表现信号：**
- 不同坡度段的 W/kg 一致性高（变异系数 <10%）
- 长爬坡（>10min）后半段 W/kg 衰减 ≤5%
- 爬坡踏频保持在 70–90 RPM 区间，不出现过度"碾车"（<60 RPM）
- VAM 与 W/kg 匹配（同坡度下 VAM 稳定）

**⚠️ 爬坡问题信号：**
- 陡坡 W/kg 远低于缓坡（说明齿比选择或踏频策略有问题）
- 长爬坡中后段功率骤降 >15%（有氧耐力不足或补给不足）
- 爬坡踏频持续 <60 RPM（过度依赖股四头肌大力量，疲劳快）
- 爬坡心率飙升但功率上不去（说明已超过阈值，糖原主导供能）

### 2.5 运动科学依据
- **功率分解**：总功率 = 重力功率 + 空气阻力功率 + 滚动阻力功率 + 加速功率。坡度 >6% 时，重力功率占比 >80%，因此 W/kg 是爬坡的决定性指标。
- **坡度-功率关系**：在恒定 W/kg 下，爬坡速度与坡度成反比；每增加 1% 坡度，相同 W/kg 下速度约下降 10–12%。
- **肌肉纤维募集**：低踏频爬坡更多募集 II 型快肌纤维，疲劳更快；高踏频（>90 RPM）更多依赖 I 型慢肌，耐力更好但心血管成本更高。

## 3. 心率负荷 (heartRateLoad)

### 3.1 核心概念
心率是心血管系统对运动负荷的反应，反映"输入侧"生理成本。心率本身不直接代表运动强度（受温度、脱水、咖啡因、睡眠等影响），但**心率变化趋势**和**心率-功率关系**是评估有氧能力和疲劳状态的重要窗口。

### 3.2 关键指标

| 指标 | 定义 | 说明 |
|------|------|------|
| **平均心率 / 最大心率** | 骑行中心率统计值 | 需结合 LTHR 或 HRmax 解读 |
| **心率区间分布** | 各心率区间时间占比 | Z1–Z5 分布 |
| **心率上升速率** (Heart Rate Drift) | 稳态骑行中心率随时间的上升幅度 | 反映有氧基础 |
| **效率因子 EF** (Efficiency Factor) | NP / 平均心率 | EF = 骑行平均功率(或NP) / 平均心率 |
| **心率恢复** (HR Recovery) | 骑行结束后 1–2 分钟心率下降幅度 | 反映心血管适应度 |

### 3.3 心率区间分级（基于 LTHR）

| 区间 | % LTHR | 名称 | 感受 | 生理意义 |
|------|--------|------|------|----------|
| Z1 | <81% | 恢复区 | 极轻松，可正常对话 | 主动恢复、促进血流 |
| Z2 | 81–89% | 有氧耐力区 | 轻松，可完整对话 | 脂肪氧化最大、有氧基础建设 |
| Z3 | 90–94% |  Tempo/节奏区 | 稍累，对话变短 | 有氧能力提升、乳酸清除训练 |
| Z4 | 95–105% | 乳酸阈值区 | 很累，只能说短句 | 阈值提升、乳酸耐受 |
| Z5 | >106% | VO₂max/无氧区 | 极限，无法说话 | 最大摄氧量、无氧功率 |

> 注：LTHR（乳酸阈值心率）≈ 30 分钟全力骑的平均心率；对训练有素者约为 HRmax 的 85–90%。

### 3.4 解读逻辑（AI 判断规则）

**✅ 良好心率负荷信号：**
- Z2 骑行中心率漂移 ≤5%（90 分钟以上稳态）
- EF 值（NP/HR）在同强度骑行中逐周上升（有氧效率提升）
- 骑行后 1 分钟心率恢复 ≥20–30 bpm
- 心率区间分布与训练目标匹配（如恢复骑 90%+ 在 Z1–Z2）

**⚠️ 心率问题信号：**
- 相同功率下心率比平时高 5–10 bpm（疲劳未恢复、脱水、高温、生病前兆）
- Z2 骑心率漂移 >10%（有氧基础不足）
- 心率长时间"挂"在 Z4–Z5 且功率上不去（过度训练/糖原耗尽）
- 骑行后心率恢复 <12 bpm（心血管适应度差或疲劳累积）
- 心率曲线"锯齿"剧烈且与功率变化不同步（心率带佩戴问题/信号干扰）

### 3.5 运动科学依据
- **心率滞后**：心率对功率变化的响应延迟约 20–30 秒，因此心率是"滞后指标"，不适合做即时配速控制，但适合评估整体负荷。
- **心率漂移 (Cardiac Drift)**：长时间稳态骑行中，即使功率恒定，心率也会因脱水、体温升高、每搏输出量下降而逐渐上升。正常漂移率约 3–5%/小时。
- **EF 作为有氧效率指标**：EF = NP / HR，数值越高代表每跳心脏输出的机械功率越多，即有氧经济越好。同强度下 EF 上升 = 体能进步。

## 4. 功率输出 (powerOutput)

### 4.1 核心概念
功率是踩踏产生的机械功率（瓦特），是自行车运动中最客观、最即时的"输出侧"指标。功率直接反映骑手做了多少功，不受心率滞后、温度、疲劳感知等主观因素干扰。

### 4.2 关键指标

| 指标 | 定义 | 说明 |
|------|------|------|
| **平均功率** (Average Power) | 全程功率的算术平均值 | 受滑行/下坡低功率拉低 |
| **标准化功率 NP** (Normalized Power) | 模拟"如果全程恒定功率骑、产生相同生理压力"的功率 | 见计算方法 |
| **最大功率 / 峰值功率** | 短时间内最高功率 | 反映无氧爆发力 |
| **功体比 W/kg** | 功率 / 体重 | 不同体重间的比较基准 |
| **功率曲线** (Power Curve) | 各时长（5s/1min/5min/20min/1hr）最大输出 | 全面刻画能力分布 |
| **有效功率比** | NP / 平均功率 = VI | 即变速系数 |

**NP 计算方法（Allen & Coggan）：**
1. 计算 30 秒滑动平均功率
2. 将每个 30 秒值取 4 次方
3. 对所有 4 次方值取平均
4. 对平均值取 4 次方根 → NP

> 4 次方的数学意义：高强度功率对生理压力的贡献是非线性的——高强度时间翻倍，生理消耗不止翻倍。

### 4.3 功率区间分级（基于 FTP）

| 区间 | % FTP | 名称 | 可持续时间 | 主要供能系统 |
|------|-------|------|------------|--------------|
| Z1 | <55% | 主动恢复 | 数小时 | 脂肪氧化 |
| Z2 | 56–75% | 有氧耐力 | 2–6 小时 | 脂肪+少量糖原 |
| Z3 | 76–90% | Tempo | 30–90 分钟 | 糖原为主 |
| Z4 | 91–105% | 乳酸阈值 | 20–60 分钟 | 糖原+乳酸 |
| Z5 | 106–120% | VO₂max | 3–8 分钟 | 无氧糖酵解 |
| Z6 | 121–150% | 无氧能力 | 30 秒–3 分钟 | 无氧糖酵解 |
| Z7 | >150% | 神经肌肉功率 | <30 秒 | ATP-CP |

### 4.4 解读逻辑（AI 判断规则）

**✅ 良好功率输出信号：**
- NP 与平均功率差值小（VI 接近 1.0，说明节奏稳定）
- 功率曲线各时长成比例（如 1min ≈ 120–130% FTP，5min ≈ 105–110% FTP）
- 峰值功率与平均功率比合理（短骑行比值高，长骑行比值低）
- 同 FTP 下 W/kg 随训练提升

**⚠️ 功率问题信号：**
- 平均功率远低于 NP（VI >1.2）：说明功率波动大，可能是频繁拉扯或路况差
- 功率曲线畸形（如 5min 功率 > 20min 功率的 110%）：说明测试不充分或体能下降
- 长时间功率"挂"在 Z3（"哑区"）：训练无明确针对性，既不练恢复也不练阈值
- 功率数据出现突然跳变/死区：功率计校准问题或传感器故障

### 4.5 运动科学依据
- **功率 vs 速度**：速度受风阻、坡度、坡度影响极大（风阻 ∝ 速度³），而功率直接对应人体做功，是更可比的指标。
- **NP 的生理学基础**：研究表明，4 次方加权的功率平均值与心率反应、血乳酸反应的相关性最好——即 NP 最能代表"身体实际承受了多大生理压力"。
- **FTP 定义**：功能性阈值功率 = 最大可持续 1 小时的平均功率，约等于 95% 的 20 分钟全力骑功率。FTP 是划分所有功率区间的基准。

## 5. 骑行强度与训练负荷 (intensityAndTrainingLoad)

### 5.1 核心概念
训练负荷是对一次骑行"给身体施加了多少训练刺激"的量化。强度（多努力）和时长（多久）共同决定负荷大小。核心指标是 TSS（训练压力分）和 IF（强度因子）。

### 5.2 关键指标

| 指标 | 定义 | 公式 |
|------|------|------|
| **强度因子 IF** (Intensity Factor) | 本次骑行 NP 相对于 FTP 的强度 | IF = NP / FTP |
| **训练压力分 TSS** (Training Stress Score) | 综合强度×时长的训练负荷量化 | TSS = IF² × 时长(小时) × 100 |
| **相对强度 RS** | 另一种负荷表达方式 | RS = (秒数 × NP × IF) / (FTP × 3600) × 100 |
| **每个 TSS 耗时** | 负荷效率 | 总时长 / TSS |

**TSS 公式推导：**
- TSS = (t × NP × IF) / (FTP × 3600) × 100
- 化简：TSS = IF² × hours × 100
- 含义：以 FTP 强度骑 1 小时 = 100 TSS

### 5.3 强度与负荷分级

**IF 强度分级：**

| IF 范围 | 强度等级 | 典型场景 |
|---------|----------|----------|
| <0.60 | 恢复骑 | 恢复日、热身/冷身 |
| 0.60–0.70 | 轻松耐力 | 长距离基础骑 |
| 0.71–0.85 | 中等耐力 | 常规训练骑 |
| 0.86–0.95 | 节奏/Tempo | 有氧耐力强化 |
| 0.96–1.05 | 阈值 | 阈值训练/计时赛 |
| 1.06–1.20 | VO₂max | 高强度间歇 |
| >1.20 | 无氧/冲刺 | 短距离全力 |

**单次骑行 TSS 参考：**

| TSS | 负荷等级 | 恢复时间建议 |
|-----|----------|--------------|
| <100 | 低 | 几小时 |
| 100–200 | 中等 | 1 天 |
| 200–300 | 较高 | 1–2 天 |
| 300–450 | 高 | 2–3 天 |
| >450 | 极高 | 3–5 天（比赛/长途） |

### 5.4 解读逻辑（AI 判断规则）

**✅ 合理训练负荷信号：**
- 训练骑 IF 与目标匹配（恢复骑 <0.65，基础骑 0.65–0.75，阈值骑 0.85–0.95）
- TSS 与骑手水平匹配（业余骑手周 TSS 建议 300–600，职业 800–1200+）
- 高 TSS 骑行后有足够的低强度恢复日
- 80/20 分布：约 80% 时间在 Z1–Z2，20% 在 Z4+

**⚠️ 负荷问题信号：**
- 大部分时间"挂"在 Z3（IF 0.75–0.85），即"垃圾里程"——既不够轻松恢复，也不够刺激提升
- 连续多日高 TSS（>250/天）无恢复：过度训练风险
- 单次骑行 IF 很高但时长极短（IF>1.1 但 TSS<50）：说明是短间歇，需关注总训练量
- TSS 与主观 RPE 严重不符：FTP 可能需要重新测试

### 5.5 运动科学依据
- **TSS 的平方项意义**：IF 取平方意味着强度对负荷的贡献是指数级的——IF 从 0.7 升到 0.9（+29%），负荷增加 65%。这解释了为什么"稍微骑快一点"累得多。
- **80/20 极化训练**：研究一致表明，精英耐力运动员约 75–85% 的训练时间在低强度（Z1–Z2），15–25% 在高强度（Z4+），很少在 Z3。"垃圾里程"指的就是大量 Z3 训练。
- **慢性负荷与急性负荷比 (ACWR)**：虽然单次骑行看不全，但 TSS 是累积计算 CTL（慢性训练负荷）和 ATL（急性训练负荷）的基础。

## 6. 踏频策略 (cadenceStrategy)

### 6.1 核心概念
踏频（Cadence，RPM）是每分钟踩踏的圈数。同一功率可以通过"高踏频+轻齿比"或"低踏频+重齿比"实现，两种方式的生理成本不同：高踏频心血管成本高、肌肉力量成本低；低踏频反之。

### 6.2 关键指标

| 指标 | 定义 | 说明 |
|------|------|------|
| **平均踏频** | 全程踏频均值 | 需排除停车/滑行段 |
| **踏频分布** | 各踏频区间的时间占比 | 70–80 / 80–90 / 90–100 / 100+ |
| **踏频变异系数** | 踏频标准差 / 平均踏频 | 反映踩踏流畅度 |
| **功率-踏频关系** | 不同功率下骑手选择的踏频 | 高功率时踏频是否下降 |
| **传感器对齐** | 踏频数据与功率数据的时间同步性 | 用于判断数据质量 |

### 6.3 典型踏频参考

| 场景 | 推荐踏频 (RPM) | 说明 |
|------|---------------|------|
| 平路耐力骑 | 85–95 | 大多数骑手的舒适区 |
| 平路计时赛 | 90–100 | 职业车手常见 |
| 缓坡 (3–6%) | 80–90 | 比平路略低 |
| 陡坡 (>8%) | 65–80 | 齿比限制+肌肉力量需求 |
| 冲刺 | 100–120+ | 高踏频爆发力 |
| 起步/低速 | <60 | 低速+大齿比 |

**精英 vs 休闲骑手：**
- 精英车手：90–105 RPM（平路），高有氧能力支撑高踏频的心血管成本
- 休闲骑手：70–85 RPM（平路），更依赖肌肉力量而非心肺

### 6.4 解读逻辑（AI 判断规则）

**✅ 良好踏频策略信号：**
- 平路踏频集中在 85–95 RPM 区间（分布窄、变异小）
- 坡度增加时踏频自然下降（缓坡降 5 RPM，陡坡降 10–20 RPM）
- 功率上升时踏频保持稳定（不出现"踩不动"式的踏频崩塌）
- 踏频数据与功率数据时间对齐良好（无明显延迟）

**⚠️ 踏频问题信号：**
- 平路踏频持续 <70 RPM：过度碾车，股四头肌疲劳快，不适合长距离
- 平路踏频持续 >110 RPM：踏频过高，心血管成本大，经济性差
- 踏频波动极大（标准差 >15 RPM）：踩踏不流畅，齿比选择不当
- 功率变化时踏频几乎不变：可能是齿比选择太固定，没有根据路况换挡
- 踏频数据与功率数据不同步：传感器配对问题，数据可信度下降

### 6.5 运动科学依据
- **功率 = 踏频 × 扭矩**：P = Cadence × Torque × 常数。同一功率下，高踏频对应低扭矩（每脚力量小），低踏频对应高扭矩（每脚力量大）。
- **代谢经济性悖论**：实验室测得最低耗氧的踏频是 60–70 RPM，但骑手自发选择 85–95 RPM。原因是高踏频虽然耗氧略高，但肌肉骨骼应力小、延迟局部肌肉疲劳，对长距离更有利。
- **肌肉纤维募集**：低踏频高扭矩更多募集 II 型快肌（力量大但易疲劳）；高踏频低扭矩更多募集 I 型慢肌（耐力好但力量小）。
- **踏频与效率因子**：在相同功率下，个体最优踏频是"心血管成本 + 肌肉成本"总和最低的点，因人而异。

## 7. 跨传感器配合 (crossSensorCoordination)

### 7.1 核心概念
跨传感器分析是指将功率、心率、踏频、速度、坡度等多维度数据放在同一时间窗口下对比，观察它们之间的关系如何随骑行进程变化。这些关系（而非单一指标）才能揭示真正的生理状态和训练效果。

### 7.2 关键跨传感器指标

| 指标 | 定义 | 公式 / 方法 | 意义 |
|------|------|-------------|------|
| **有氧解耦 Pw:Hr** | 功率-心率比的漂移程度 | (前半段 NP/HR - 后半段 NP/HR) / 前半段 NP/HR × 100% | 有氧耐力深度 |
| **效率因子 EF** | 功率/心率比值 | EF = NP / 平均HR | 有氧效率 |
| **踏频-功率同步性** | 踏频变化是否跟随功率变化 | 时间相关系数 | 踩踏技术流畅度 |
| **速度-功率比** (V/P) | 速度 / 功率 | 滚动阻力+风阻+坡度的综合效率 | 骑行经济性/风阻优势 |
| **心率-踏频关系** | 同功率下心率随踏频的变化 | 对比不同踏频下的 HR | 个体最优踏频判断 |
| **坡度-功率匹配** | 坡度变化与功率变化的时间对齐 | 延迟时间分析 | 配速前瞻性 |

### 7.3 基准范围与解读

**有氧解耦 (Pw:Hr Decoupling) 分级：**

| 解耦值 | 等级 | 含义 |
|--------|------|------|
| <5% | 优秀 | 有氧基础扎实，耐力持久 |
| 5–10% | 中等 | 有氧基础尚可，长距离有衰减 |
| 10–15% | 偏弱 | 有氧基础不足，长距离明显掉速 |
| >15% | 差 | 有氧基础薄弱，需大量 Z2 训练 |

> 测试条件：90 分钟以上 Z2 稳态骑行，前后各取 20 分钟计算 NP/HR 比值。

**效率因子 EF 参考：**
- 初学者：EF < 1.5
- 训练有素：EF 1.5–2.0
- 高水平：EF 2.0–2.5
- 精英：EF > 2.5

> EF = NP / 平均心率（单位：W/bpm）。同强度下 EF 越高 = 有氧效率越好。

### 7.4 解读逻辑（AI 判断规则）

**✅ 良好跨传感器关系信号：**
- 稳态骑行中 Pw:Hr 解耦 <5%（有氧基础好）
- 同功率下 EF 逐周提升（体能进步）
- 功率变化时踏频同步调整（换挡时机合理）
- 速度/功率比稳定（没有异常风阻或机械问题）
- 心率上升滞后于功率上升约 20–30 秒（正常生理响应）

**⚠️ 跨传感器异常信号：**
- 功率不变但心率持续上升（Pw:Hr 解耦大 → 有氧耐力不足/脱水/高温）
- 功率上升但心率不升（心率带故障/心率已达平台）
- 踏频骤变但功率不变（可能是换挡失误或踩踏技术问题）
- 速度-功率比突然下降（爆胎/刹车蹭碟/逆风增强）
- 心率和功率数据时间轴错位 >3 秒（传感器配对/同步问题）
- 高踏频下心率异常高（超出该踏频应有的心血管成本 → 心肺瓶颈）
- 低踏频下功率上不去但心率已高 → 肌肉力量瓶颈

### 7.5 运动科学依据
- **解耦的生理学机制**：长时间稳态运动中，脱水导致血容量下降、每搏输出量减少，心脏需要跳更快来维持心输出量——因此相同功率下心率逐渐上升。这就是"cardiac drift"。
- **EF 作为训练追踪指标**：效率因子 = 输出 / 输入，是"性价比"指标。随着有氧能力提升，完成相同功率所需的心率下降，EF 上升。这比单看功率或单看心率都更能反映真实进步。
- **多传感器三角验证**：单一指标可能因传感器误差而失真，但功率-心率-踏频三者交叉验证后，异常就很难隐藏。例如：功率高但心率不高 → 可能是滑行段拉低平均功率；功率正常但心率极高 → 可能是爬坡段肌肉在做功但心肺跟不上。

## 附录：数据质量校验规则（AI 前置检查）

在解读任何维度之前，AI 应先检查数据质量：

1. **功率数据完整性**：缺失率 <5%，无长时间死区（>2 分钟功率为 0 但在骑行中）
2. **心率信号连续性**：无频繁断连/尖峰（>250 bpm 或 <30 bpm 的异常值）
3. **踏频同步性**：踏频变化与功率变化的时间延迟 <1 秒
4. **坡度数据合理性**：坡度范围 -15% ~ +20%，无极端跳变
5. **FTP 基准有效性**：FTP 在过去 3–4 个月内测试过，否则 TSS/IF 解读需谨慎
