# Demo 前端设计基线与模块记录

> 当前任务：`DEMO-UI-01` 骑行记录与月度热力图，`Review`（2026-10-26，追加标题栏及 PMC 入口）。
> 范围：Demo 前端的视觉、交互与页面实现；不改后端行为。  
> 视觉依据：仓库 `UED参考/` 中的 Stoic iOS 页面，仅提炼设计语言，不复用其品牌资产。

## 1. 协作与交付方式

用户逐个提供模块需求。每个模块开始前，先确认目标用户、入口、主要流程、页面内容和必要状态；实现后同步本记录和开发台账，完成相关自检并提供可交互预览。当前模块交由用户检查，收到明确验收后再推进下一个模块。用户反馈的调整先回到当前模块内完成。

需求尚未明确的内容标为待确认，不根据当前浏览器标签、旧计划或现有页面擅自推定模块范围。

## 2. UED 视觉基线

从参考截图提炼以下规则：

- 使用浅灰暖白作为主要页面底色，以黑色文字和深色重点区域形成清晰对比。
- 标题短而醒目，正文层级清楚；使用系统中文字体，正文保持易读。
- 页面聚焦一个主要任务，留出充分呼吸空间；内容多时分段呈现，不把所有信息塞入首屏。
- 卡片与按钮采用明显但克制的圆角；主操作使用胶囊按钮或深色高对比按钮。
- 渐变只用于 AI 状态或明确的 AI 体验区域，不用作大面积背景或装饰。
- 不复制 Stoic 的品牌名、图标、插画、文案或其他专有视觉资产。
- 移动端优先，并保证桌面布局有明确的最大宽度与合理伸展；不出现横向溢出。
- 触控目标至少 44×44 px；正文字号至少 16 px，辅助说明至少 14 px；状态和图表不能只靠颜色表达。

当前全局样式已存在一组与该方向一致的基础变量，后续按模块需要复用并谨慎扩充：`--bg`、`--surface`、`--ink`、`--muted`、`--line`、`--accent`、`--ai-start`、`--ai-end`、`--radius-card`、`--radius-control`。

## 3. 前后端边界

- 可调整页面结构、样式、前端组件、客户端交互、加载/错误/空状态和展示用的演示数据。
- 不修改 `app/api/` 路由、领域规则、解析器、认证、持久化、仓储、AI 服务、数据合同或服务端业务行为。
- 如果页面需要已有数据，沿用当前页面调用方式和现有合同；若需求依赖后端新增能力，先记录为边界或待议项，不在本阶段实现。
- Next.js 页面可以继续使用现有 Server Component 读取方式。只有需要浏览器状态、事件处理或浏览器 API 的小块交互才使用 Client Component。

## 5. 模块记录

### DEMO-UI-01 · 骑行记录与月度热力图

- 状态：`Review`（2026-10-26）。
- 用户目标：快速了解累计骑行情况，浏览月份骑行分布，并按时间倒序进入任意骑行详情。
- 入口：底部「骑行」，沿用 `/import`。单行页面头部保留骑行图标，以「骑行记录」作为唯一可见标题；标题继承既有品牌文字的字号与字重，右侧为「个人资料」(`/profile`) 和「PMC」(`/pmc`) 入口。PMC 目前没有业务数据或既有页面，先提供明确标注为 Demo 的前端占位页；时间轴顶部提供「上传记录」按钮，以弹窗承载已有上传组件。
- 信息顺序：页标题 → 汇总与月度热力图概览卡 → 全部骑行时间轴。
- 概览卡：累计骑行次数、总里程、本周次数与里程和月度热力图组合在同一张卡片中；卡内通过细分隔线区分汇总与热力图，热力图保持左右内边距，避免月份标题贴边。
- 热力图：按月展示日期方格，不显示日期数字；每天一个缩小的正方形，按日期顺序排布。相邻月份在同一横向滚动带连续排列，不按整页分页或吸附；通过左右滑动浏览月份。移除当前年月标题、今天/前后月控制和底部图例；今天继续在对应方格内用独立标记表示。方格不可选择、不筛选下方记录。
- 热力口径：按北京时间将记录归入开始日期；每天累计距离分为无骑行、低于 20 km、20–49.9 km、50–99.9 km、100 km 及以上五档。距离表示骑行量，不标为训练强度。今天使用独立点标识；方格无日期文字。
- 总汇总：累计骑行次数与可用总里程覆盖全部记录；本周统计从北京时间周一计算至今天。距离缺失时显示「未记录」，不编造数值。页面不再展示月度汇总。
- 全量时间轴：展示所有骑行，不受当前月份或日期影响；按开始时间倒序，最新记录在前。低对比浅底上传按钮作为时间轴首项，保留图标和文字入口；时间轴仅绘制一条连续主线，上传入口有独立起始节点，每个日期标题对应一个节点，同一天多条骑行记录共用该日期节点；没有日期的记录放在列表末尾并标为「日期未记录」，该组同样只有一个节点。卡片以较紧凑的内边距和圆角展示时间、来源、公里数及可靠时长/均速/爬升；演示数据使用单独的轻标签，点击进入既有详情路由；无记录时显示空状态。页面底部增加导航安全留白。
- 精简展示：移除选中日期摘要、按日记录卡片、月度汇总、示例记录折叠区和异常状态预览入口；保留页面级加载与错误反馈及真实上传能力。
- 数据边界：保持现有 session 和仓储读取；只向客户端传递日期、来源及列表所需概要指标，不传轨迹，不修改后端。
- 验收条件：相邻月份连续横滑；小方格无日期数字且今天可辨识；顶部总汇总正确；页面头部标题可见且右侧个人资料和 PMC 入口可用；PMC 入口打开 Demo 占位页且可返回骑行记录；时间轴展示全量并按时间倒序；上传入口可用；详情跳转可用；空状态可用；390/768/1280 px 无横向溢出。
- 实现文件：`app/import/page.tsx`、`app/components/ride-calendar-heatmap.tsx`、`app/components/ride-calendar.module.css`、`app/pmc/page.tsx`、`app/pmc/pmc.module.css`、`src/ui/ride-calendar.ts`、`tests/ride-calendar.test.ts`。
