## 单窗口对话与会话过期 · Review

- **交付**　`9ad9ff0` 将会话收进同一窗口，用户通过历史分页回看旧消息。旧消息默认隐藏并保存在浏览器。在消息顶部下拉、向上滚动滚轮或按 Page Up 可分批加载，后续分页保留阅读位置。上一轮结束满 24 小时后自动切换会话上下文。欢迎语、开场推荐与符合条件的今日训练卡在发送首条消息后收起。骑行数据解读和训练计划生成快捷按钮常驻输入框左上方。导入回执归入起始会话，详情返回可定位来源，主动发起计划讨论时带入明确的计划版本。
- **检查**　此前全量 929 项测试通过。本轮类型检查、差异格式检查和 390×844 浏览器自检通过，覆盖新会话默认隐藏历史、触摸下拉、滚轮和键盘分页、后续分页锚点、实时过期、首问上下文隔离、发送后训练卡收起及详情返回。
- **下拉阻尼检查**　浏览器确认轻拉和回拉后松手只回弹，拉过阈值松手才加载历史。桌面滚轮需在顶部累积一定距离，键盘分页继续可用。
- **快捷按钮检查**　320 和 390 像素宽度下验证按钮左对齐于输入框上方、续聊时可用、点击发送正确问题及草稿保留。两条问句经现有路由进入 Agent 主链。
- **首次引导检查**　浏览器覆盖首次进入、未提问就刷新、已有访问会话但无本地聊天记录，以及两种原型演示模式切换。320×740 和 390×844 视口下，首次引导首屏可见欢迎语，卡片位于欢迎语与推荐之间。
- **开场推荐检查**　回访开场的欢迎语、三条竖排推荐和「换一换」相邻，并随消息同步滚动。消息较少时整组靠近屏幕下方。「换一换」的图标为 12 像素，触控高度为 44 像素，可切换三组问题。点击问题直接发送，续聊时收起推荐。
- **回复卡片检查**　用模拟聊天回复验证文字完整显示后才出卡。320 和 390 像素宽度下核对距离和时长的视觉层级，点击卡片跳转对应详情，深度解读独立打开抽屉。澄清时可继续提交明确的骑行选择。类型检查和 19 项相关测试通过。
- **骑行导航检查**　移除全屏等待遮罩，慢请求显示延迟出现的线形进度。骑行记录的标题和底部导航在内容替换时保持稳定，详情加载态沿用目标页的返回和页签结构。模拟慢速切换、内容淡入及减少动态效果通过浏览器检查，生产构建和 929 项测试通过。
- **验收**　浏览器自检使用聊天和训练接口替身，待用户验收。体验规则见 [UX Design](../UX%20Design.md)，技术边界见 [AI-Spec](../AI-Spec_对话Agent能力规约_v2.md)。
