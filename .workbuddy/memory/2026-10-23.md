## 修正：删掉 manifest 的 id 是错的（实际跑挂了）

  - `fontFor` 找不到 PingFang SC 等家族时不再 `throw`，回落任意可用字体（原来会整盘失败）。
  - 失败**回滚**：`main()` 记录运行前 `page.children` 的 id 集合，catch 里把新增节点全部 `remove()`，不再留半成品。
