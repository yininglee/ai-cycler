## 修正：删掉 manifest 的 id 是错的（实际跑挂了）

- 用户实跑报错：`in setPluginData: Cannot set private plugin data in a plugin without an ID. Make sure your plugin manifest has a valid "id" field.`
- **教训：Figma dev 插件可以不要 `id`，但一旦调用 `setPluginData` 就必须有 `id`。** 保留/删除 id 的取舍应以「是否用 pluginData」为准，不能凭印象删。
- 处置：**彻底移除对 pluginData 的依赖**（三处 `frame.setPluginData` / `page.setPluginData` 全删，那只是诊断信息），而不是再编一个假 id。manifest 保持无 `id`。
- 附带加固：
  - `fontFor` 找不到 PingFang SC 等家族时不再 `throw`，回落任意可用字体（原来会整盘失败）。
  - 失败**回滚**：`main()` 记录运行前 `page.children` 的 id 集合，catch 里把新增节点全部 `remove()`，不再留半成品。
  - 残留清理：跑之前只删「0 子节点 且 名字匹配 `^0[12] · (AI 骑行伙伴|骑行日历)`」的 Frame。用户文件里那 2 个空 Frame 就是上次失败留下的，重跑会自动清掉。
- 用 `SEED_LEFTOVERS=1` 预置 2 个空 Frame 做了回归，`cleanedEmptyFrames: 2`，最终仍是 2 屏 / 56 文字层 / 216 节点，SVG 字节数与修正前完全一致（视觉无回归）。
