# Cycler 1.1.0 账号与第三方骑行导入开发规划

## 阶段一 · 账号与数据隔离

1. 沿用仓库的 Node SQLite 运行环境。新增账号及会话表，邮箱唯一。使用带随机盐的 scrypt 存储密码摘要，保存会话令牌的哈希和过期时间。注册和登录限流，退出撤销当前会话，删除账号撤销该账号的所有会话。
2. 在 Next.js 请求入口校验注册账号会话。未登录页面请求跳转到账号页，业务 API 返回 401。路由和服务继续以服务端会话的 owner ID 查询及写入。旧访客会话无法进入应用。
3. 使用账号页处理登录和注册，从「我的」进入账号管理。登录后复原站内目的页面。浏览器内聊天历史、草稿和导入回执按账号使用独立存储键。覆盖直接访问、跨设备登录、不同账号访问和退出会话的回归用例。

## 阶段二 · 顽鹿与行者导入

1. 两个入口复用文件导入服务，为新记录保存平台标识。沿用单次 50 MB 校验和同一 owner 的文件哈希去重。
2. 顽鹿继续复用已落库的同步适配器和数据归属校验。配置绑定的 owner 可主动连接、同步和断开。其余用户可导入平台导出的文件。
3. 行者增加 OAuth 发起、一次性 state 回调、服务端凭据保存及刷新。回调使用发起授权时的 Cycler 登录会话。手动同步时从公开运动列表筛选最近骑行，按 Cycler 账号、行者账号和活动 ID 去重。使用行者网页 FIT 导出接口，当前实测现有 OAuth 令牌可用。下载仅接受行者返回的预期存储地址，复用 FIT 解析并保留脱敏后的标准化数据。已同步的摘要可保留原记录 ID 并补全，新记录无法读取 FIT 时保存摘要。
4. 覆盖有效文件、重复文件、来源标记、OAuth state 错误与重放、跨账号访问、令牌失效、限流及同步中断。解绑取消进行中的拉取，保留已完成导入的记录。运行类型检查、完整测试和生产构建。

## 联调与部署

首期沿用单实例和持久数据目录。生产部署使用 HTTPS，注册行者回调地址与应用凭据。顽鹿真实同步沿用已有联调配置。需由持有许可的测试账号验证真实骑行的数据覆盖、平台权限及重复导入结果，再向用户开放连接入口。

使用 Cycler 邮箱账号联调顽鹿时，先在测试实例上注册账号，再由服务端操作者查询该账号的内部 ID，并填入 `ONELAP_SYNC_OWNER_ID`。在项目根目录运行以下命令，用已注册的测试邮箱替换示例中的地址。命令使用当前实例的 `LOCAL_DATA_DIR`，默认读取项目内的 `.local-data`。

```sh
node --env-file-if-exists=.env.local --input-type=module -e '
  import { findAccountCredentials } from "./src/auth/account-store.ts";
  const account = findAccountCredentials(process.argv[1].trim().toLowerCase());
  if (account) console.log(account.id);
  else {
    console.error("当前实例没有这个账号");
    process.exitCode = 1;
  }
' rider@example.com
```

行者同步配置使用行者开发者后台创建的第三方应用 ID 和密钥。将 `XINGZHE_CLIENT_ID`、`XINGZHE_CLIENT_SECRET`、`XINGZHE_REDIRECT_URI` 和至少 32 字符的随机 `SESSION_SECRET` 放在服务端 `.env.local`，设 `XINGZHE_SYNC_ENABLED=true` 后重启服务。[行者开放平台接入说明](https://developer.imxingzhe.com/docs/intro/)

行者后台的「网站」和「授权回调域」都按完整 URL 校验。在同一台机器联调时，「网站」可填 `http://127.0.0.1:3001/`，「授权回调域」可填 `http://127.0.0.1:3001/api/platform/xingzhe/callback`。这两个值通过网页表单校验，仍需用真实行者应用验证保存和授权。将 `XINGZHE_REDIRECT_URI` 配成与后台一致的完整回调地址，并通过 `http://127.0.0.1:3001` 登录 Cycler。访问与回调使用同一主机名，以便回调带上原 Cycler 会话。从其他设备联调，或行者后台限制保存本机地址时，使用 Cycler 的 HTTPS 访问地址和对应回调。

从「运动平台与导入 → 行者」点击「连接行者」，在行者完成只读授权后返回 Cycler，再点击「立即同步」。本人列表应出现带行者来源的骑行。有可用 FIT 的旧摘要应补全原记录，二次同步应计为重复。同步过程中在另一标签页断开连接，可验证进行中的拉取停止。
