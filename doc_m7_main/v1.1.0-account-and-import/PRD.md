# Cycler 1.1.0 账号与第三方骑行导入 PRD

## 目标与范围

骑友注册后可以在另一台设备登录，继续查看自己的骑行记录、个人资料和训练计划。已在顽鹿或行者记录的骑行，可以带着来源标识导入 Cycler。

本功能分支基于 1.0.0 的 `m7-main`。本期依次交付账号和数据隔离、顽鹿导入、行者导入。登录支持邮箱和密码。邮箱验证、找回密码、第三方身份登录及训练方案优化属于后续工作。

## 账号

- 首次打开 Cycler 时进入登录页。用邮箱和至少 12 个字符的密码注册，成功后直接登录。邮箱忽略大小写。同一邮箱只能注册一个账号。
- 对话、骑行记录与导入、训练计划和个人资料均需登录。打开应用内链接时先登录，成功后回到原页面。直接访问业务 API 时，未登录请求返回 401。
- 登录后，从「我的」确认当前账号并可退出。退出后回到登录页。登录失败时统一提示邮箱或密码有误。
- 新账号首次进入聊天首页时，在欢迎语下方显示引导卡片，可完善个人资料、导入骑行或制定训练计划。引导按账号展示一次，随后刷新、重新登录或换设备时进入普通开场。
- 骑行、资料、训练计划与执行反馈、解读缓存、平台连接及导入状态归当前账号所有。服务端从会话确定数据归属。浏览器聊天记录按账号显示，保存在使用过的浏览器里。新账号从空数据开始，历史访客记录迁移留待后续设计。

## 顽鹿与行者导入

- 从「同步／导入骑行」选择顽鹿或行者。两个平台均提供带来源标识的 FIT／GPX 文件导入，上传和解析沿用现有骑行导入规则。
- 在顽鹿页，可直接上传一个 OTM 导出的 ZIP，或一次选择多个 FIT。系统读取 ZIP 中的 FIT，包括子目录里的文件。每批最多 200 个 FIT，上传总大小最多 100 MB，单个 FIT 最多 50 MB。
- 批量导入按当前 Cycler 账号和 FIT 文件内容去重。改名或换 ZIP 后再次上传同一个 FIT，列表仍只有一条。导入结束后显示新增、跳过重复和失败数量，并列出失败文件及原因。单个 FIT 失败时，继续导入同批其他文件。
- 顽鹿保留现有受控单账号连接和「立即同步」流程。该入口只向服务端配置绑定的身份开放。多用户云端授权依赖顽鹿提供正式合作接口。
- 行者使用开放平台 OAuth 只读授权。每次手动同步检查活动列表的前三页，每页最多 20 条。Cycler 优先读取行者提供的 FIT，显示文件包含的轨迹和传感器数据，也会补全可匹配的历史摘要。FIT 不可用时，显示列表提供的开始时间、距离和总时间。仍可手动导入 FIT／GPX。[行者授权文档](https://developer.imxingzhe.com/docs/intro/) · [行者运动 API](https://developer.imxingzhe.com/docs/openapi/activities/)
- 平台同步显示新增、重复、失败数量。重新同步或重新关联原有平台账号时，已记录的源活动只保留一条。断开连接后停止读取平台数据，已导入的记录仍可查看或删除。如需撤销行者侧授予 Cycler 的权限，可在行者账号中管理授权。
- 行者同步会单独显示已删除记录的跳过数量。用户可点击「重新导入已删除记录」，从当前连接的行者账号重新导入同步范围内已在 Cycler 删除的骑行。

## 验收

1. 注册 A、B 两个账号，在新浏览器登录 A 能查看 A 的资料和骑行。B 的骑行列表和详情、资料、训练计划、解读与平台连接中均看不到 A 的私有数据。
2. 未登录时，直接打开应用页面会进入登录页，调用业务 API 返回 401。登录后回到原页面。退出后当前会话失效，旧会话无法再读取 A 的私有数据。切换账号时当前浏览器的聊天记录和导入回执跟随身份切换。
3. 从两家平台的文件入口导入同一有效文件两次，当前账号只出现一条记录。新导入的记录标明来源。两账号可分别导入相同文件。
4. 配置平台许可凭据后分别验证真实授权或连接、首次同步、重复同步和断开连接。缺少平台凭据时，可以验证文件导入和模拟上游响应下的同步流程。
5. 上传包含子目录、重复 FIT 和损坏 FIT 的 ZIP。有效记录进入当前账号，损坏文件单独报错。再多选上传 ZIP 中相同的 FIT，系统跳过重复项。另一账号可分别导入相同文件。

## iGPSPORT（迹驰）接入调研

- iGPSPORT 是后续接入候选。当前 Cycler 可从通用文件入口导入已取得的 FIT。iGPSPORT 专属来源标识、批量入口和云端连接属于候选功能。
- 要取得码表保存的原始 FIT，可通过 USB 从支持的设备复制 `iGPSPORT/Activities` 中的文件。官方手册已确认 iGS618、iGS630S 支持这一方式。iGPSPORT App 的官方资料也提到 FIT 下载，账号历史能否批量下载仍待实测。 [iGS618 手册](https://global.igpsport.com/File/pdf/igs618-%E8%AF%B4%E6%98%8E%E4%B9%A6%E4%B8%AD%E6%96%87%E7%89%88.pdf) · [iGS630S 手册](https://arg.igpsport.com/descargas/iGS630S.pdf) · [iGPSPORT App 数据说明](https://prod.zh.igpsport.com/service/mobile/api/docs/privacy)
- iGPSPORT 开放平台可邮件申请 OAuth 2.0 接入。用户授权后从云端同步骑行是候选体验。历史补拉范围、原始 FIT 下载和新记录触发方式，以平台提供的开发文档和真实账号联调为准。 [iGPSPORT 开放平台](https://www.igpsport.com/support/app/openapi)
