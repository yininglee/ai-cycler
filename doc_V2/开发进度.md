## 维护规则

- 任务实施前读取本文件当前任务卡、相关 PRD/技术方案及必要的源码；发现范围/架构/风险变化时同步记录。
- 自检通过后进入 `Review`，附验证证据、预览入口和用户检查清单；等待用户确认期间不开始下一项计划任务。
- 每项进入 `Review` 时在当前任务卡写入面向非技术用户的验收汇报：V1 的对应问题、本项实际改变及是否接入当前骑后功能、验证结果与可观察样例、尚未解决的事项、请用户判断的验收问题；向用户汇报同样内容，不要求读代码或运行测试。技术自检不是用户验收。
- 用户明确验收后追加一条 `Done` 完成记录，再更新里程碑计数；沉默或自动化通过都不算用户验收。
- 被新优先级打断的既有任务应保留原交付证据，并单独记录 `Paused`；不得擅自当作通过或取消。
- 状态值：`Backlog / Ready / In Progress / Review / Blocked / Done / Paused`。
