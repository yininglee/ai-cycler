# ITEM-V008｜个人资料与生理阈值事实合同评审

> 日期：2026-08-20  
> 状态：`ACCEPTED`  
> 当前阶段：v0.1 证据型Demo / G1「Demo核心价值」  
> 边界：来源审计与两项冲突已确认，进入实现；心率区间、新AI和真实账号仍不在本项。

## 1. 工作项目标

为后续心率分析、功率解释、历史比较和AI最小上下文建立可追溯的单用户资料事实源，并提供可预览的资料查看/编辑入口。

## 2. 依据审计与冲突

### 2.1 已核对来源

- 版本路线图：功能模块×版本矩阵、单次字段开放计划、v0.1后续切片与v0.2 Alpha范围；
- PRD：6.2骑行数据看板的个人资料与FTP/心率前置、7.5.1数据分层、7.5.4原子能力门、7.9安全与兜底、7.12版本放行；
- 研发指南：阶段2无AI详情与数据契约、个人资料字段边界、原子能力与后续Feature/History依赖；
- 已接受决策：DEC-033（功率与可信FTP分离）、DEC-034（最大心率估算与用户覆盖）；
- 实际代码：当前为Next.js单用户Demo，无个人资料Schema、页面、API或持久化适配器。

### 2.2 冲突/待确认项

#### C-001｜Demo本地存储与PRD PostgreSQL目标架构

- PRD 7.5.1：体能档案、FTP/心率配置、偏好的权威存储为PostgreSQL，带来源与版本；
- 路线图/当前工作项：v0.1先做本地单用户资料编辑，v0.2 Alpha再升级账号绑定、多用户持久化、权限和删除；
- 影响：决定本次Demo的刷新后数据是否保留，以及未来切换数据库时的适配边界；
- 推荐：V008使用浏览器`localStorage`作为Demo持久化适配器，严格实现`UserProfile v0.1`合同；将PostgreSQL保留为Alpha权威存储目标，切换时不改变领域字段和来源合同。

#### C-002｜用户手动FTP的可信语义

- PRD 6.2/7.5.4与DEC-033要求FTP带来源、时间和可信状态；无可信FTP时不得生成依赖FTP的区间、IF、TSS或训练负荷结论；
- 当前工作项仅允许用户在资料中录入FTP，不实现自动估算；尚未明确“保存后的用户输入”是否立即满足可信状态；
- 影响：决定后续原子能力`verifiedFtp`何时打开，以及功率区间/IF/TSS等能力的准入；
- 推荐：用户主动填写并保存、通过范围校验的FTP记录为`source=user_provided`、`trustStatus=user_confirmed`，可作为可信基线；仍不得称为实测，且不在V008中启用IF/TSS等依赖能力。

### 2.3 用户确认结果

- C-001：用户确认使用浏览器`localStorage`作为v0.1 Demo单用户适配器，PostgreSQL留至Alpha账号绑定与多用户持久化；已记录为[DEC-056](../project-ledger/decision-log.md#dec-056确认v008-demo个人资料存储适配器)。
- C-002：用户确认保存后的手动FTP记录为`user_provided + user_confirmed`，但不称为实测、不自动估算、不在V008启用依赖FTP的高级训练能力；已记录为[DEC-057](../project-ledger/decision-log.md#dec-057确认v008用户手动ftp的可信语义)。

### 2.4 非冲突的版本边界解释

PRD 6.2描述心率区间展示，但其前置条件是当前生效最大心率和独立版本化区间规则；路线图与本工作项将区间规则/分布后置。因此V008只建立资料和最大心率基线，不实现心率区间计算或分析Tab区间图。若用户希望本项同时实现区间，需另行确认规则版本与测试范围。

## 3. 拟实现范围（确认后）

- `UserProfile v0.1`领域合同：年龄、身高、体重、最大心率、FTP及各自来源/时间；系统估算最大心率增加公式版本；
- 默认最大心率：年龄有效时按`220 - 年龄`生成`system_estimated`；用户值优先；删除用户值后恢复估算；年龄变化不覆盖用户值；骑行最高心率不回写资料；
- FTP：仅用户录入，不自动估算；按确认后的可信语义记录；
- 本地单用户资料页面/编辑态，保持Demo刷新行为可解释；
- 确定性合同、范围校验、覆盖/删除/年龄变化回归测试；
- 模型、RAG、Function Calling、骑后AI输出和真实账号权限均不在本项。

## 4. 验收标准（确认后冻结）

- 合同通过正常值、缺失值、边界值和非法值测试；
- 最大心率来源、创建/更新时间、公式版本完整可追溯；
- 用户覆盖、删除恢复、年龄变化规则行为正确；
- FTP不自动生成，可信状态与来源语义符合用户确认；
- 移动端/桌面端资料页面可预览；刷新后Demo行为与选定存储适配器一致；
- 不影响已验收的ITEM-V007详情页与80/80既有测试。
