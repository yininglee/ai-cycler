# Demo 前端设计基线与模块记录

> 当前任务：`DEMO-UI-01` 骑行热力图，`Review`（2026-10-22）。  
> 范围：Demo 前端的视觉、交互与页面实现；不改后端行为。  
> 视觉依据：仓库 `UED参考/` 中的 Stoic iOS 页面，仅提炼设计语言，不复用其品牌资产。

## 1. 协作与交付方式

用户逐个提供模块需求。每个模块开始前，先确认目标用户、入口、主要流程、页面内容和必要状态；实现后同步本记录和开发台账，完成相关自检并提供可交互预览。当前模块交由用户检查，收到明确验收后再推进下一个模块。用户反馈的调整先回到当前模块内完成。

需求尚未明确的内容标为待确认，不根据当前浏览器标签、旧计划或现有页面擅自推定模块范围。

## 2. UED 视觉基线

从参考截图提炼以下规则：

- 使用浅灰暖白作为主要页面底色，以黑色文字和深色重点区域形成清晰对比。
- 标题短而醒目，正文层级清楚；使用系统中文字体，正文保持易读。
- 页面聚焦一个主要任务，留出充分呼吸空间；内容多时分段呈现，不把所有信息塞入首屏。
- 卡片与按钮采用明显但克制的圆角；主操作使用胶囊按钮或深色高对比按钮。
- 渐变只用于 AI 状态或明确的 AI 体验区域，不用作大面积背景或装饰。
- 不复制 Stoic 的品牌名、图标、插画、文案或其他专有视觉资产。
- 移动端优先，并保证桌面布局有明确的最大宽度与合理伸展；不出现横向溢出。
- 触控目标至少 44×44 px；正文字号至少 16 px，辅助说明至少 14 px；状态和图表不能只靠颜色表达。

当前全局样式已存在一组与该方向一致的基础变量，后续按模块需要复用并谨慎扩充：`--bg`、`--surface`、`--ink`、`--muted`、`--line`、`--accent`、`--ai-start`、`--ai-end`、`--radius-card`、`--radius-control`。

## 3. 前后端边界

- 可调整页面结构、样式、前端组件、客户端交互、加载/错误/空状态和展示用的演示数据。
- 不修改 `app/api/` 路由、领域规则、解析器、认证、持久化、仓储、AI 服务、数据合同或服务端业务行为。
- 如果页面需要已有数据，沿用当前页面调用方式和现有合同；若需求依赖后端新增能力，先记录为边界或待议项，不在本阶段实现。
- Next.js 页面可以继续使用现有 Server Component 读取方式。只有需要浏览器状态、事件处理或浏览器 API 的小块交互才使用 Client Component。

## 5. 模块记录

### DEMO-UI-01 · 骑行日历

- 状态：`Review`。
- 用户目标：按月查看骑行分布、汇总和某日的全部记录，再进入骑行详情。
- 入口：底部「骑行」，沿用 `/import`。顶部提供导入按钮，以弹窗承载已有上传组件；次要示例入口折叠到页面底部。
- 信息顺序：页标题 → 月度日历热力图 → 月度汇总 → 今日/选中日期记录 → 次要示例及异常预览入口。
- 热力图：采用月度日期方格，不显示日期数字；每月按日期顺序排布为 7 列小方格，多个自然月在同一横向滚动带内连续排列，不按整页分页或吸附。默认滚到当前月，支持左右滑动、前后月按钮、返回今天及跳转最近一次骑行；按钮切月时选中该月第一天。
- 热力口径：按北京时间将记录归入开始日期；每天累计距离分为无骑行、低于 20 km、20–49.9 km、50–99.9 km、100 km 及以上五档黑白灰层级。距离表示骑行量，不标为训练强度。存在记录但无有效距离时用最浅活动色并显示「距离未记录」，不编造数值。
- 悬浮摘要：点击日期时显示日期、次数和逐次公里数；日历下方同时更新该日卡片。点击日历外、关闭按钮或 Escape 收起悬浮摘要，保留日期选择。空日期显示零次和无记录文案。
- 今天与选中态：今天方格使用独立圆点及「今天」标识，选中日期使用外框，两种状态可叠加。日期按钮提供完整日期、记录次数、公里数和当前日期的无障碍标签。
- 月度汇总：当前查看月份的累计距离、骑行次数、骑行时长、累计爬升；无记录时距离/次数显示 0，存在记录但指标全缺失时该指标显示「未记录」。
- 日期记录：今天标题为「今日骑行」，其他日期为「M 月 D 日的骑行」；卡片显示来源/演示标记、时间、公里数及可靠时长/均速/爬升，点击进入现有详情路由。无记录时展示空状态。
- 数据边界：保持现有 session 和仓储读取；只向客户端传递日期、来源及列表所需概要指标，不传轨迹。没有合法日期的记录单独放入「日期未记录」，不强行放进今天或月度统计。
- 验收条件：横向连续浏览月份，不按整页截断；小方格无日期数字；今日和选中标识可区分；同日多次骑行逐次展示；日/月汇总一致；空日与空月可用；详情跳转和导入入口可用；390/768/1280 px 无横向溢出。
- 实现文件：`app/import/page.tsx`、`app/components/ride-calendar-heatmap.tsx`、`app/components/ride-calendar.module.css`、`src/ui/ride-calendar.ts`、`tests/ride-calendar.test.ts`。
- 自检结果：月度热力图已在 `http://localhost:3000/import` 浏览器预览；点击 2026-10-05 显示 1 次、30.4 km，点击「下个月」切至 2026 年 11 月并更新月度汇总。`npm run typecheck`、`npm run build` 与全量测试 706/706 通过。
- 预览入口：`/import`（沿用现有骑行底部导航入口）。
- 用户反馈：2026-10-15 明确要求文档放入 V2.1 文件夹，并指定骑行日历、悬浮摘要、今天状态、月汇总、日期记录与空状态。
- 用户反馈：2026-10-22 修正视觉方向：保留“按月”，改为无日期数字的小方格热力图；相邻月在单一横向区域连续滑动，不按周或整页分页。
