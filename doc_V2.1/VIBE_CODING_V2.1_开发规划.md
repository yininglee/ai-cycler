## 1. 价值闭环

用户导入 FIT/GPX 后，AI 解读不再围着"详情页平均数"打转，而是围绕**运动科学知识库定义的维度化关键指标**（配速的 VI、爬坡的 W/kg 与 VAM、心率的 EF 与有氧解耦……）组织证据，并为每个维度提供**基准分级参照 + 解读逻辑线索**，让"骑得怎么样、意味着什么"有更专业、更口径一致的解释。

## 2. 工作约定

- 继承 V2 全部工作约定：`Backlog / Ready / In Progress / Review / Blocked / Done / Paused` 七态；最多一个主 `In Progress` 或 `Review`；自检通过进 `Review` 并停止；只有用户明确验收才记 `Done`；每项验收汇报写在对应工作项下。
- **本轮不改变 V2 里程碑（R2-1/R2-2/R2-3）的完成数**，V2.1 是独立路线图；不动 V1 生产链，默认仍走 V1 引擎。
- **知识库替换为硬约束**：新知识库 `ride-kb-2.1.0` 上线后，旧 batch1 仅作只读归档，不再被任何链路引用。
- 每个派生指标 = "纯函数 + 固定点列单测 + 版本化 formulaVersion"，三者缺一不可验收。
- 本规划任务 ID 前缀 `V21`，与 V2 的 `RIDE-AI-*` 不冲突。
