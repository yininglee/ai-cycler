## 受控执行顺序

1. 先确认当前服务运行、AI 调用配置和待测数据来源；为本场次分配匿名编号。自有文件场次先说明进程内临时存储边界。
2. 仅在参与者开始任务前临时开启 AI；观察者不提前解释 AI 结果。
3. 完成观察表和评分表；保存必要的页面截图，不保存个人身份信息。
4. 场次结束立即关闭 AI 开关，核对 B0、数据 Tab 隔离和停止条件。
5. 五场完成后再生成汇总，不在中途宣布 G1 或扩大样本。
