# V017 Demo 用户测试匿名观察表 v0.1

## 使用边界

- 仅记录匿名编号 `P01`–`P05`，不记录姓名、联系方式或可识别备注。
- 每位参与者只使用一条记录，可为自己的非敏感 FIT/GPX 或指定内置样例；只记录匿名数据来源、文件类型和可见传感器，不记录文件名、精确轨迹或复制原始文件。
- 自有文件场次开始前说明：原始文件解析后不持久化，标准化记录只保存在当前 Node 进程内存，服务重启后清除。
- 观察者不在任务过程中教学、纠正或解释 AI 结论；必要的安全提示除外。
- 本表记录用户行为和原话，不替代自动合同、固定评测或 G1 决策。
