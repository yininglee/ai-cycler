- **解读机制**：各入口统一配置引擎；服务端已有解读绑定用户、记录、相关资料、模型及规则版本，打开先校验复用，明确重新解读才再生成。失败／绕过校验不缓存为成功，删除／不可见／错配响应不展示；故障原因与数据限制使用中文说明。稳定性断言提示补齐逐条证据引用要求，原校验门保留。合同见 AI-Spec §17 与 UX 场景文档。
- **工程检查**：pnpm verify 类型检查及 885/885 检查、生产构建与 git diff --check 通过。新增 6 项工程集成检查覆盖真实文件解析与去重、回执隔离／重放、明确选择恢复、成功解读持久复用、资料／引擎／可见性变化失效、失败与绕过不缓存及限制文案；脚本 Provider 仅证明链路，不证明模型质量。未新建专项测评集或批量 Run。
- **实际页面与模型**：隔离临时仓储，临时使用 V4-Flash，未改项目 .env。已检查 AI 同步入口、佳明模拟新增 2／重复 2 的回执、损坏 GPX 失败后重试、合成 FIT 文件实际导入、摘要／分析／数据及返回原对话的草稿恢复、刷新不重复追加回执。模拟平台记录经实际 V2 模型生成并通过校验，再次打开显示原生成时间，仓储 ai_requested 事件未增加；这是模拟数据上的实际模型联调，不是真实平台证明。
