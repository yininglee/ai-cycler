# ✅ FTP / NP / IF / TSS（Coggan体系，TrainingPeaks标准）
> 一套功率训练四大核心指标，**FTP是基准，NP是真实生理功率，IF是相对强度，TSS是训练负荷**

## 1. FTP ｜ Functional Threshold Power 功能阈值功率
**定义：理论上你可以稳定维持1小时的最大平均功率（瓦W）**，是所有功率区间的基准线
- 测试常用：20分钟全力测试 × 0.95，或者Ramp阶梯测试
- 用途：划分训练区间、比赛配速基准
> 例：FTP=220W，代表你大约可以持续1小时输出220W

## 2. NP ｜ Normalized Power 规范化功率
**定义：把起伏、间歇、忽快忽慢的功率，换算成同等生理消耗下的稳态功率**（30s滚动加权计算）
- 和普通平均功率区别：爬坡、起伏路、间歇赛段，**平均功率会低估真实疲劳，NP更准**
- VI变异指数 VI = NP ÷ 平均功率
  - VI≈1.02~1.05：输出很平稳（长距离耐力赛、大组稳骑）
  - VI>1.1：波动大（起伏路、绕圈赛）
> ⚠️ 不足10分钟的片段NP参考意义不大

## 3. IF ｜ Intensity Factor 强度因子
**IF = NP ÷ FTP**，这次骑行相对于你阈值的强度系数
- IF=1.0：等于FTP强度（1小时阈值全力）
- IF 0.60~0.70：低强度有氧/恢复骑
- IF 0.70~0.80：长距离耐力（磨房168这类长距离赛事常用区间）
- IF 0.80~0.90：阈值前高强度训练
- IF ≥1.0：超阈值间歇、短距离冲刺赛段

## 4. TSS ｜ Training Stress Score 训练压力分
**TSS = 骑行时长(小时) × IF² × 100**
> 定义：1小时FTP全力，TSS=100，作为基准
- 含义：综合「强度+时间」，衡量本次骑行给身体带来的总训练负荷，用来规划周负荷、恢复、看CTL/ATL/TSB状态
- 参考区间（单节课）
  - <50TSS：轻松恢复骑
  - 50~100：常规有氧训练
  - 100~150：高强度长训练
  - >200：超长距离/比赛级负荷（你168km比赛大概率会到这个区间）

# 📌 一句话串联
**用FTP做你的个人基准，NP算出这次真实生理消耗，IF看相对阈值有多猛，最后算出TSS，评估这次骑有多累、需要多久恢复。**

# 📎 延伸（你备战168km会用到）
CTL（长期负荷）、ATL（短期疲劳）、TSB状态分，就是靠每次TSS累积算出来，用来判断比赛当天状态。
