# UCI职业公路赛爬坡等级划分（HC / 1 / 2 / 3 / 4级）

> 注意：**UCI规则本身没有写死硬性数值阈值**，只规定必须对赛段爬坡做分级；三大环赛（环法/环意/环西）组委会执行实际定级，综合：**爬坡长度、平均坡度、总爬升、赛段中所处位置、是否山顶终点**，山顶终点爬坡通常自动升一级。
> 环法ASO广泛使用难度分数公式：
> **难度分 = 爬坡长度(km) × (平均坡度%)²**

| 等级                          | 难度分(ASO环法标准) | 典型长度     | 平均坡度   | 总爬升       | 说明                             |
| --------------------------- | ------------ | -------- | ------ | --------- | ------------------------------ |
| **HC级（Hors Catégorie，超纲级）** | ≥600分        | 10‑25km+ | ≥7.5%  | ≥1000m    | 最高难度，传奇大山，总成绩决战点，如图尔马莱、阿尔普‑迪埃兹 |
| **1级（Cat‑1）**               | 300‑599分     | 8‑20km   | 6‑8%   | 600‑1000m | 高难度大山，主将集团筛选，副将大量掉队            |
| **2级（Cat‑2）**               | 150‑299分     | 5‑12km   | 4.5‑7% | 300‑600m  | 集团开始分裂，突围集团形成                  |
| **3级（Cat‑3）**               | 75‑149分      | 2‑6km    | 4‑6%   | 150‑300m  | 会筛掉弱车手，车队试探节奏                  |
| **4级（Cat‑4）**               | ＜75分         | 1‑3km    | 3‑5%   | 50‑150m   | 热身小坡，大集团一般不解体，获取山地积分最低门槛       |

## 关键补充规则

1. **坡度权重高于距离**：公式对坡度做平方，代表越陡，难度会非线性暴涨；10%坡的体能消耗远大于5%坡的2倍。
2. **山顶终点加成**：同一个爬坡，如果终点设在山顶，组委会惯例升一级；例如原本2级坡直接升为1级。
3. **赛段位置影响主观定级**：放在赛段末尾的坡，车手已经疲劳，实际定级会比单纯公式算出来更高。
4. **最低评级门槛**：太短、爬升太小的坡，不予评级，不计山地王积分。

## 直观经验参考（非官方硬标准，便于自己判读路线）

- HC：12km @8%，或22km @6%
- 1级：10km @7%，或18km @5.5%
- 2级：6km @7%，或14km @4.5%
- 3级：3km @7%，或7km @4%
- 4级：1‑2km @4‑6%

## 山地王积分（环法为例，山顶终点积分更高）

- HC山顶：第一车手25分；途中HC：20分
- 1级山顶：15分；途中1级：10分
- 2级：5分；3级：2分；4级：1分
